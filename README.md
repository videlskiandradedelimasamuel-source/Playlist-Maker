# Playlist-Maker

Autor - Samuel Videlski Andrade de Lima.

Disciplina - Desenvolvimento de Página Web com Css e Framework.

Instituição - UTFPR.  

Projeto que serve como Playlist Maker, onde o usuário criará uma conta e usará a ferramenta Crate Digger para digitar artistas e músicas que ele gosta, e o site criará uma playlist com artistas e músicas semelhantes, com opções de salvar a playlist no Spotify e visualizar as playlist criadas.
